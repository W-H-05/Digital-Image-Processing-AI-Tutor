日期：2026-10-12（第十五次迭代）

【本轮起因】
用户反馈练习系统的 3 个细节问题：
① 选错了不显示正确选项（之前答错时正确项会绿色高亮，暴露答案）；
② 选错了连续答对次数要重置；
③ 最后完成闯关的正确率算法不对——第一次答错的题就算答错，
   即使后来重选答对，正确率也应按首次作答计算。

--------------------------------------------------------------------------------
  一、选错不显示正确选项
--------------------------------------------------------------------------------
PracticeLab.vue 的 optionClass 原逻辑：揭示对错后，正确项统一加 correct 类（绿框），
导致答错时也会高亮正确答案。
修复：
- 区分 showCorrect / showWrong 两种状态：
  · 答对(showCorrect=true)：正确项绿色对勾，其余淡化；
  · 答错(showWrong=true)：选中的错误项红色叉，正确项也淡化（不暴露答案）。
- 对勾图标仅 showCorrect 时显示；红叉图标仅 !showCorrect 时显示。

--------------------------------------------------------------------------------
  二、选错重置连对次数
--------------------------------------------------------------------------------
judge() 答错分支新增：streak=0、streakTier=0。
即答错瞬间连续答对计数清零，🔥 火焰计数与边框特效等级均回落，
需重新连续答对才重新累积。

--------------------------------------------------------------------------------
  三、正确率按首次作答计算
--------------------------------------------------------------------------------
原逻辑：totalCorrectCount 在每次 judge 答对时 +1，导致"首次答错后重选答对"的题
也被计入答对，正确率虚高。
修复：
- 新增 firstTryResults ref，记录每道题首次作答结果 { questionId: true/false }；
- judge() 中仅当该题 id 未记录时才写入首次结果；
- totalCorrectCount 改为 computed，统计首次答对的题数；
- restart() 和 load() 重置 firstTryResults。
- 语义：正确率 = 首次答对的题数 / 总题数；首次答错即记为错，不因重选答对而改变。

--------------------------------------------------------------------------------
  四、验证结果
--------------------------------------------------------------------------------
- 前端 npm run build 通过（16.1s）。
- 本次为纯前端改动，无需重启后端。
