--------------------------------------------------------------------------------
  一、多选题提交按钮修复
--------------------------------------------------------------------------------
根因：模板判断 `isMultiple === 1`，但 isMultiple 是 computed 已返回布尔值，
`=== 1` 恒为 false，导致「确认答案」按钮与提示不渲染。
修复：改为 `isMultiple`，多选题确认按钮恢复正常。

--------------------------------------------------------------------------------
  二、选项对错颜色修正（核心 bug）
--------------------------------------------------------------------------------
根因：学生端题目接口 listForStudent 故意不返回 correctKeys（避免泄露答案），
而前端 isCorrectKey 读的是 current.correctKeys（恒为空），导致揭示对错后
所有选项都走 else 分支被判为「错误」，正确选项也显示红叉。
修复：
- 新增 correctKeys ref，judge() 从 answer 接口返回的 res.correctKeys 赋值；
- isCorrectKey/isWrongPicked/optionClass 均改为读该 ref；
- 揭示后：正确项绿色边框 + 绿色圆形对勾(✓)，选中的错误项红色边框 + 红色圆叉(✗)，
  未选中的其余项淡化(半透明)。

--------------------------------------------------------------------------------
  三、练习通关页 + 自动退出锁定
--------------------------------------------------------------------------------
PracticeLab.vue：
- 新增 finished 状态与通关页面：🏆 表情弹跳 + "恭喜你通过闯关"渐变标题 +
  彩带飘落动画 + 答对/总题数/正确率统计卡片 + "再练一次"/"返回目录"按钮。
- nextQuestion 答到最后一题 → finished=true + emit('unlock')。
- restart 重新从第一题开始（清空连对/计数）+ emit('lock')。
- 返回目录 → emit('back')。

PackView.vue：
- 新增 practiceLocked 独立状态（不再用 activeKey==='practice' 判断锁定）。
- PracticeLab 挂载时 emit('lock') 锁定目录+禁用AI；通关 emit('unlock') 解锁；
  返回目录 emit('back') 清空 activeKey 回到占位提示。
- 锁定逻辑：目录项 practiceLocked 时加 disabled 样式(pointer-events:none) +
  打开函数拦截提示；AI 助手 practiceLocked 时显示禁用提示。

--------------------------------------------------------------------------------
  四、LibreOffice 说明
--------------------------------------------------------------------------------
LibreOffice 是「外部系统依赖」，不是 Maven/npm 依赖，需在部署机器上单独安装：
- 后端通过 ProcessBuilder 调用 soffice --headless 命令转 PPT→PDF（PreviewServiceImpl）；
- 路径由 .env 的 SOFFICE_PATH 配置（AppProperties.sofficePath）；
- 未安装时 PPT/PPTX 预览会失败并提示"请确认服务器已安装 LibreOffice"。
Windows 可去 libreoffice.org 下载安装；Linux 用 apt/yum 安装 libreoffice 或
仅 libreoffice-impress。已在 README 补充说明。
