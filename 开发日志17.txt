================================================================================
  《数字图像处理》课程 AI 助教系统 —— 开发日志 17（练习题题目与选项支持图片）
================================================================================

日期：2026-10-12（第十七次迭代）

【本轮起因】
用户要求：练习题的题目和选项支持图片格式。

--------------------------------------------------------------------------------
  一、数据模型
--------------------------------------------------------------------------------
- 新增 migration_v9.sql：practice_question 表加 stem_image varchar(512) 字段
  （题干图片路径）。
- 选项图片直接存在 options_json 每个选项对象里，选项结构由 {key,text} 扩展为
  {key,text,image}，无需新增表结构。
- PracticeQuestion 实体加 stemImage 字段。

--------------------------------------------------------------------------------
  二、后端 PracticeController
--------------------------------------------------------------------------------
- 新增 POST /teacher/practice/upload-image：教师上传图片（题干图/选项图），
  保存到 uploads/practice/yyyyMMdd/ 目录，返回可访问 URL /uploads/practice/...。
- listForTeacher / listForStudent 返回 stemImage 字段，选项含 image。
- add / update 支持 stemImage 字段。

--------------------------------------------------------------------------------
  三、前端
--------------------------------------------------------------------------------
教师端 PacksView 练习管理抽屉：
- 题干图片：上传按钮 + 预览 + 移除。
- 每个选项加图片上传按钮 + 预览 + 移除。
- 已有题目列表显示题干图、选项图缩略图。
- 校验改为：题干文本或题干图片至少一个；选项文本或选项图片至少一个。

学生端 PracticeLab：
- 题干下方显示题干图片（最大宽 100%、高 240px）。
- 选项内显示选项图片缩略图（最大 120x70）。

--------------------------------------------------------------------------------
  四、验证结果
--------------------------------------------------------------------------------
- 后端 mvn clean package 成功；前端 npm run build 成功。
- 接口实测：创建带图片题目，学生端正确返回 stemImage 和选项 image 字段。
- 测试数据已清理。
